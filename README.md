# Doraemon Drawing using Matplotlib 🐱🤖

This project creates a Doraemon character using Python's Matplotlib
library by plotting geometric shapes and curves.

It demonstrates creative use of data visualization libraries for
artistic and educational purposes.

## Features
- Draws Doraemon using Matplotlib
- Uses circles, lines, and curves
- Beginner-friendly Python project
- No external image files used

## Technologies Used
- Python
- Matplotlib
- NumPy

## How to Run the Project
1. Install required libraries:
   pip install matplotlib numpy
2. Run the Python file:
   python doraemon.py
3. Doraemon image will be displayed in a graph window

## Output
The program displays a Doraemon cartoon created using Matplotlib plots.

## Learning Outcome
- Understanding Matplotlib shapes
- Coordinate systems
- Creative coding with Python
